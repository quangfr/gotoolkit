# Go-Toolkit

Votre tableau de bord centralise tous vos outils, vos favoris et votre base de connaissances locale.

## 1. Vos modules actifs
- **Mémo** : Votre carnet de notes enrichi avec IA (rédaction, schémas Mermaid, RAG).
- **Grid** : Vos données structurées et mappings générés par l'IA.

## 2. Super-pouvoirs
- Cliquez sur **⚡︎ Super-pouvoirs** pour comprendre comment GoToolkit vous aide à structurer votre pensée, concevoir des produits orientés données et accélérer vos livrables.

## 3. Configuration de l'IA (Réglages)
Cliquez sur **⌘ Paramètres** pour configurer vos services :
- **Moteur IA** : Choisissez entre **OpenRouter** (recommandé pour la diversité des modèles) ou **OpenAI**.
- **Clé API privée** : Votre clé reste stockée localement dans votre navigateur.
- **Modèles & Raisonnement** : Sélectionnez le modèle (ex: GPT-5) et ajustez l'effort de raisonnement.
- **Presets de Prompt** : Personnalisez les instructions pour les modes **Demander**, **Explorer**, **Suggérer** ou **Éditer**.

## 4. Mes favoris
- Épinglez vos mémos ou grilles les plus utilisés. Ils apparaissent en haut pour un accès rapide.

## 5. Espace en ligne (Partages)
- Retrouvez ici tous les documents que vous avez partagés via un lien public. Vous pouvez voir les statistiques de consultation et gérer vos publications.

## 6. Bibliothèque locale
- Tous vos travaux privés restés sur votre machine. C'est ici que sont stockés vos brouillons (drafts) sauvegardés automatiquement.

## 7. Feedback & Retours
- Utilisez le bouton **☄ Feedback** pour signaler un bug ou proposer une idée. Si vous avez un token admin, vous pouvez consulter la liste complète des retours.

## 8. Notes de version & Feuille de route
- Cliquez sur le numéro de version (v...) pour consulter les dernières **Releases** et voir ce qui est prévu dans la **Feuille de route**.

# Module Assist

L'Assist est votre compagnon IA présent dans Mémo et Grid. Il puise dans votre mémoire locale pour répondre à vos besoins.

## 1. Mémoire (Base de connaissances)
- Importez vos documents (PDF, Word, Excel, Markdown, JSON, etc.).
- Ils sont indexés localement (RAG) et ne quittent jamais votre ordinateur.
- Cliquez sur **⌗ Mémoire** pour gérer vos fichiers actifs.

## 2. Deux modes principaux
- **⌕ Explorer** : L'IA cherche dans vos documents importés pour donner une réponse sourcée avec des références précises.
- **↬ Demander** : Idéal pour brainstormer ou générer du contenu neuf sans forcément fouiller dans vos fichiers.

## 3. Autres outils Assist
- **✦ Suggérer** : Pour obtenir des idées complémentaires.
- **✂ Éditer** : Pour transformer une sélection de texte existante.
- **◇ Dessiner** : Pour générer des structures de schémas (Mermaid).

## 4. Transcription vocale
- Cliquez sur l'icône **◉** dans la zone de saisie pour transcrire vos paroles en temps réel. Utile pour dicter des notes ou des questions rapidement.

# Module Mémo

Mémo est votre espace de rédaction intelligent.

## 1. Écriture Markdown
- Titres, listes, tableaux, code, liens... tout le standard Markdown est supporté.
- Sauvegarde automatique en temps réel.

## 2. IA et Sélection
- Sélectionnez un texte pour demander une modification via l'Assist (**✂ Éditer**).
- L'IA vous propose un changement : vous pouvez alors **✓ Garder** la modification ou **✗ Annuler** pour revenir au texte original.

## 3. Schémas Mermaid
- Insérez des diagrammes (flux, séquences, gantt) directement via le bouton Mermaid.
- L'IA peut vous aider à générer le code Mermaid pour vos architectures.

## 4. Export & Partage
- Exportez en **Markdown** ou **JSON**.
- Générez un lien de partage pour diffuser votre note en lecture seule.

# Module Grid

Grid permet de structurer et générer des données tabulaires.

## 1. Templates IA
- **Structure de données** : Pour documenter des APIs ou modèles.
- **Mapping de données** : Pour aligner deux systèmes (ex: Salesforce ↔ Interne).
- **Données fictives** : Pour générer des exemples réalistes.

## 2. Manipulation des données
- Filtres, tris, et focus sur colonnes (en appuyant sur le header).
- Export direct en **CSV** ou **JSON**.
