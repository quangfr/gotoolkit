# Go-Toolkit

La page d'accueil est votre tableau de bord. Vous y découvrez tous les modules, gérez vos préférences IA, consultez votre bibiothèque locale et vos partages.

## 1. Vos modules en un coup d'œil
- Accédez à **Mémo** (votre carnet de notes intelligent avec voix et schémas) et **Grid** (vos données structurées).

## 2. Deux modes pour utiliser Assist : Explorer vs Conseiller
- **Mode Explorer** : vous posez des questions à votre base de documents. L'Assist cherche dans vos fichiers importés et vous ramène des réponses documentées.
- **Mode Conseiller** : l'Assist vous propose du contenu neuf, des suggestions créatives. Idéal pour brainstormer ou générer des idées à partir de rien.
- Vous basculez entre les deux modes dans les paramètres, ou directement dans la barre Assist selon le module.

## 3. Configurer votre IA
- Cliquez sur **Réglages** pour ouvrir le panneau de configuration.
- **Choisir votre modèle** : OpenAI (ChatGPT), Ollama (local), WebLLM (dans le navigateur), OpenRouter (accès à plusieurs modèles).
- **Clé API privée** : si vous choisissez OpenAI ou Ollama, entrez votre clé ou URL locale. Elle ne quitte jamais votre navigateur.
- **Modèle & température** : sélectionnez le modèle exact (GPT-4, Claude, etc.) et la température pour contrôler la créativité (0 = logique pure, 1 = créatif).
- **Tous vos paramètres sont sauvegardés** : fermer et rouvrir le navigateur, tout reste.

## 4. Vos favoris épinglés
- Vous pouvez épingler vos mémos ou grilles préférés pour les retrouver en haut de la page.
- Un petit cœur vous permet de gérer vos favoris directement depuis la page d'accueil.

## 5. Espace en ligne : vos partages
- Tous les documents que vous avez partagés apparaissent dans **"☍ Espace en ligne"**.
- Ce sont vos mémos ou grilles que vous avez diffusés via un lien court.
- Cliquez sur l'un d'eux pour le rouvrir, le modifier ou renvoyer le lien de partage.
- Vous pouvez aussi voir combien de fois il a été consulté et quand il a été créé.

## 6. Bibliothèque locale : vos brouillons
- **"⬠ Bibliothèque locale"** contient tous vos travaux en cours : les mémos et grilles non (encore) partagés.
- C'est votre zone de travail privée : rien ne sort d'ici tant que vous ne décidez pas de partager.
- Vous y retrouvez aussi vos brouillons (drafts) sauvegardés automatiquement, même si vous n'avez pas explicitement enregistré.
- Vous pouvez renommer, archiver ou supprimer vos documents depuis cette galerie.

## 7. Retours et support : Feedback
- Un bouton **"☄ Feedback"** vous permet de remonter des bugs ou de soumettre des suggestions.
- Si vous êtes admin (token fourni), vous accédez aussi à la **liste des retours** reçus : vous voyez ce que les utilisateurs ont signalé, traitez les bugs, et planifiez les améliorations.
- Un **"+ Ajouter"** vous permet d'enregistrer rapidement un retour ou une remarque directement depuis la liste.

## 8. Apprendre et explorer
- La page d'accueil propose aussi des **Releases** (quoi de neuf cette semaine) et une **Roadmap** (ce qui arrive).
- Une section **"Super-pouvoirs"** explique comment GoToolkit aide les Product Owners, les managers et les créatifs à réfléchir plus vite.
- Des liens directs vers la documentation et les guides d'utilisation vous accompagnent à chaque étape.

# Module Assist

L'Assist est votre compagnon IA présent dans tous les modules. C'est une barre latérale qui vous aide à explorer vos documents, poser des questions et enrichir votre contenu sans quitter votre travail.

## 1. Votre base de connaissance personnelle
- Importez vos documents (PDF, Word, PowerPoint, Excel, texte) une seule fois. Ils restent chez vous, en local, jamais envoyés ailleurs.
- La barre d'Assist les indexe automatiquement et les rend consultables instantanément. Un compteur vous montre combien de documents sont actifs.
- Vous pouvez activer/désactiver un document pour qu'il alimente ou non vos recherches, sans le supprimer.

## 2. Poser une question et obtenir une réponse contextualisée
- Tapez votre question dans le champ de saisie. L'Assist cherche dans vos documents les passages les plus pertinents.
- La réponse vous est donnée accompagnée de références précises : vous voyez d'où vient chaque information (« Document: Rapport_Q4, Section 2 »).
- Si vous cliquez sur une référence, l'Assist vous montre l'extrait complet dans un panneau de prévisualisation, pour vérifier ou approfondir.

## 3. Travailler avec plusieurs documents à la fois
- Vous pouvez charger un rapport, un plan, des notes, même plusieurs versions du même document.
- L'Assist les combine intelligemment : il cherche les passages pertinents partout et les classe par pertinence, jamais par hasard.
- Chaque passage reste lié à sa source, donc vous savez toujours qui a dit quoi et où.

## 4. Historique de conversation
- Votre discussion reste sauvegardée localement. Vous pouvez fermer le navigateur et rouvrir : vos questions et réponses y sont.
- Vous pouvez effacer l'historique d'un seul clic si vous voulez recommencer, ou le conserver pour revenir sur un sujet plus tard.

## 5. Assistance au contenu dans Mémo
- Dans le module Mémo, sélectionner du texte ouvre une petite palette flottante : demandez à l'Assist de **réécrire**, **clarifier**, **résumer** ou **approfondir** votre passage en un clic.
- Les suggestions de l'IA apparaissent directement dans l'éditeur avec un code couleur : les passages modifiés sont surlignés en jaune, vous pouvez les approuver en un clic ou les rejeter.
- Dans tous les modules, le panneau Assist propose aussi de générer du contenu qui s'injecte directement dans votre travail.

# Module Mémo

Mémo est votre carnet de notes riche, où vous écrivez, structurez et enrichissez vos idées avec l'aide de l'IA. Tout se sauvegarde automatiquement chez vous, localement.

## 1. Écrire et mettre en forme
- L'éditeur supporte tous les formats : titres, listes à puces, numérotées, tableaux, images, liens, gras, italique, souligné, barré.
- Vous écrivez comme dans Word, mais tout est sauvegardé automatiquement. Aucune action requise, aucun risque de perte.
- Créez plusieurs pages/onglets dans le même mémo : changez d'onglet d'un clic, renommez-les comme vous le souhaitez.

## 2. Améliorer votre texte avec l'IA en 1 clic
- Sélectionnez un passage et une petite palette flottante apparaît.
- Vous pouvez demander à l'IA de :
  - **Réécrire** : transforme votre texte pour le rendre plus clair, plus fluide
  - **Clarifier** : explique et développe votre idée
  - **Résumer** : condense votre texte en gardant l'essentiel
  - **Approfondir** : ajoute plus de détail et de contexte
- L'IA génère une suggestion qui s'affiche en jaune dans votre texte. Vous validez (elle remplace le texte original) ou vous rejetez (elle disparaît).

## 3. Deux modes pour travailler avec l'IA
- **Mode Édition** (par défaut) : l'IA vous aide à améliorer ce que vous avez écrit, en retouchant vos propres mots.
- **Mode Suggestion** : l'IA génère du contenu neuf, des idées complètes que vous pouvez insérer ou combiner avec votre texte.
- Vous changez de mode à tout moment via le sélecteur dans la barre d'Assist.

## 4. Importer vos documents pour enrichir vos notes
- Cliquez sur le compteur de documents dans l'Assist pour ouvrir votre base de connaissance.
- Importez vos fichiers (PDF, Word, Excel, etc.). Ils sont immédiatement indexés.
- Quand vous posez une question dans l'Assist, l'IA puise dans vos documents pour enrichir sa réponse.
- Vous pouvez aussi cocher/décocher des documents pour en inclure ou exclure certains de vos recherches.

## 5. Poser des questions à votre base de documents
- Tapez une question dans le champ de l'Assist (à droite).
- L'IA fouille vos documents importés et vous donne une réponse avec des références précises.
- Vous pouvez cliquer sur chaque référence pour voir l'extrait complet du document.
- Posez autant de questions que vous le souhaitez : tout est sauvegardé dans votre historique local.

## 6. Enregistrement vocal et transcription
- Transformez vos réunions ou vos pensées en texte sans quitter votre note.
- Cliquez sur l'icône **Micro** pour démarrer un enregistrement. La transcription s'affiche en temps réel ou après l'envoi (via AssemblyAI).
- Le texte transcrit peut être inséré directement dans votre mémo, résumé par l'IA, ou utilisé comme base pour de nouvelles idées.

## 7. Intégration de schémas (Draw)
- Un dessin vaut mille mots : insérez des diagrammes directement dans vos mémos.
- Utilisez l'outil de dessin intégré (basé sur Excalidraw) pour créer des flux, des architectures ou des croquis rapides.
- L'IA peut vous aider à générer des structures de diagrammes (Mermaid) que vous pouvez ensuite éditer visuellement.

## 8. Exporter votre mémo
- **Markdown** : exportez votre mémo en fichier .md pour l'utiliser dans Notion, Obsidian ou tout autre outil.
- **JSON** : exportez/importez le mémo complet avec tous vos onglets, formatages et métadonnées pour une sauvegarde totale.
- Vous pouvez aussi partager votre mémo via un lien court : les destinataires le voient en lecture seule, mais conservent accès à votre formatage, vos images et vos schémas.

## 9. Cas d'usage pour consultants et Product Owners
- **Prise de notes de réunion** : enregistrez la voix, obtenez la transcription, et structurez le compte-rendu avec l'Assist.
- **Spécifications techniques** : combinez texte descriptif, schémas d'architecture (Draw) et données de référence (Grid).
- **Brainstorming** : jetez vos idées à la voix, laissez l'IA les organiser, et illustrez-les avec des diagrammes.

# Module Grid

Grid est votre tableau intelligent : explorez des données, générez des exemples, cartographiez des structures. L'IA remplissez les lignes, vous analysez et triez.

## 1. Trois templates pour trois besoins
- **Structure de données** : schéma arborescent montrant les champs, types, formats et définitions. Réponse : un tableau où chaque ligne = un champ. Utile pour documenter une API, une base de données, ou une migration.
- **Mapping de données** : alignez deux systèmes côte à côte pour voir qui correspond à qui. Par exemple : champs Salesforce ↔ champs interne. Réponse : un tableau d'appariement avec détails.
- **Données fictives** : générez des exemples pour tester, concevoir, ou faire des démos. Réponse : un tableau rempli de données réalistes.

## 2. Créer une grille avec l'IA
- Sélectionnez votre template (Structure, Mapping, ou Données fictives).
- Décrivez votre scénario : *"Créer une liste de clients avec nom, email, pays et date d'inscription"*.
- L'IA génère les colonnes et les lignes automatiquement.
- Vous pouvez ajouter plus de lignes, les éditer, les supprimer, ou regenerer avec une autre description.

## 3. Naviguer et filtrer vos données
- **Onglets multiples** : chaque onglet = une perspective différente (ex: Clients, Commandes, Factures).
- **Filtres** : cliquez sur une colonne pour filtrer (montrer seulement les « actifs », par exemple).
- **Tri** : cliquez sur le header pour trier A→Z ou inversement.
- **Colonnes focus** : appuyez sur les colonnes importantes pour les ramener à gauche.

## 4. Exporter vos données
- **CSV** : ouvrez dans Excel, Google Sheets, ou tout outil de données.
- **JSON** : export structuré pour intégrer dans votre code ou base de données.

## 5. Cas d'usage pour consultants et Product Owners
- **Audit de données** : documenter la structure d'une source de données existante (CRM, ERP, API).
- **Migration** : créer un mapping colonne-par-colonne pour passer d'un système à un autre, vérifier la cohérence.
- **Conception de schéma** : prototyper une nouvelle base de données ou une feuille de calcul avant de développer.
- **Simulation** : générer des données réalistes pour des tests, des présentations, des démos clients.
- **Répertoire** : créer rapidement une liste (ressources, stakeholders, dépendances) avec descriptions.
- **Spécification** : documenter un mapping d'intégration ou un format de données pour les développeurs.
